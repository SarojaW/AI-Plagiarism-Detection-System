# 🔍 AI-Based Plagiarism Detection System

An AI-based plagiarism detection web application built with Python, Streamlit, Sentence Transformers, and Machine Learning.

The system compares a source text with a submitted text using semantic similarity, word overlap, and text-length difference. These features are passed to a trained machine-learning classifier to determine whether plagiarism is detected.

## 🚀 Features

- Compare source and submitted text
- Semantic similarity using Sentence Transformers
- Cosine similarity calculation
- Word-overlap analysis
- Unique word-length difference
- Machine-learning based plagiarism classification
- Interactive Streamlit web interface
- Displays similarity percentage and analysis metrics
- Plagiarism decision based on ML prediction and semantic similarity threshold

## 🧠 Machine Learning Approach

The project uses a dataset containing:

- `source_text`
- `plagiarized_text`
- `label`

The text data is cleaned by converting it to lowercase and removing punctuation.

For each source/submitted text pair, the following features are generated:

1. **Semantic Similarity** — calculated using embeddings generated by the `all-MiniLM-L6-v2` Sentence Transformer model and cosine similarity.
2. **Word Overlap** — measures the overlap between unique words in the source and submitted texts.
3. **Length Difference** — calculates the difference between the number of unique words in the two texts.

These features are used to train and compare multiple classification models.

## 🤖 Models Evaluated

- Logistic Regression
- Random Forest
- Gaussian Naive Bayes
- Support Vector Machine (SVM)

The selected model in the project notebook is Logistic Regression based on the evaluation performed.

## 📊 Model Evaluation

The dataset contains 370 text pairs.

The models were evaluated using an 80/20 train-test split.

| Model | Accuracy |
|---|---:|
| Logistic Regression | 75.68% |
| SVM | 74.32% |
| Random Forest | 68.92% |
| Gaussian Naive Bayes | 67.57% |

> Accuracy values are based on the single train-test split used in the project notebook.

## 📓 Running the Notebook

The notebook `3.ipynb` contains the model development workflow.

Run the notebook before running the application if the trained model file needs to be regenerated.

The notebook:

1. Loads the dataset
2. Cleans the text
3. Generates Sentence Transformer embeddings
4. Calculates comparison features
5. Splits the dataset into training and testing sets
6. Trains multiple classification models
7. Evaluates model performance
8. Selects the best-performing model
9. Saves the trained model as `plagiarismmodel.pkl`

## ⚠️ Limitations

- The model is trained on a relatively small dataset.
- Results depend on the quality and diversity of the training data.
- Semantic similarity does not guarantee that two texts are plagiarized.
- The system is intended as a plagiarism screening tool rather than a replacement for human review.
- The current implementation compares two provided text passages rather than searching the internet or external document databases.
